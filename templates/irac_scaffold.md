# IRAC 论证脚手架（生成侧）

> 用途：在写 AI 回答 / 作业 / 法律意见之前，先把论证结构外化。逻辑体检（`logic_linter.py`）负责事后定位，这份脚手架负责事前预防。
> 依据：System L（AAAI-26）把 IRAC 作为法律推理骨架；IRAC-R1（ICML-26）证明结构化 IRAC 比泛化 CoT 更有效。

## 0. 三条硬规则

1. **先争点，后结论**：没有争点句，不写“因此”。
2. **先规范，后事实**：每条规范必须核验名称、时效、版本；每条事实必须对应一个要件。
3. **先反方，后结论**：至少写一个反方论证和一个例外/但书，再收束结论。

## 1. 争点清单（Issue）

| # | 争点（一句话） | 对应请求/抗辩 | 优先级 |
|---|---|---|---|
| 1 |  |  | 高/中/低 |
| 2 |  |  |  |

- 争点必须用“是否/能否/如何”表述；不要用“关于……的问题”这种模糊句。
- 多争点时，标明审理/论证顺序；互斥争点用“若……则……”分开。

## 2. 规范检索（Rule）

| 争点 | 法律名称 + 条文号 | 时效状态 | 版本/施行日 | 与争点的对应 |
|---|---|---|---|---|
| 1 | 《…》第…条 | 有效/已废止/已修改 |  |  |
| 2 |  |  |  |  |

- 引用前跑一遍 `python scripts/statute_verifier.py --law "…" --article "…"`，核对后在 `--record` 留痕。
- 新旧法衔接：先说明时间效力规定，再选适用规范；不要旧法新法混用。
- 同位阶冲突：先做特别法/一般法、新法/旧法分析。

## 3. 要件事实表（Fact）

| 规范要件 | 本案事实 | 证据 | 是否满足 | 缺口 |
|---|---|---|---|---|
| 要件 1 |  |  | 是/否/待证 |  |
| 要件 2 |  |  |  |  |

- 只写有法律意义的事实；背景、情绪、道德评价放“背景”段，不进要件表。
- 缺证据的写“待证”，不要用“显然”“众所周知”替代。

## 4. 涵摄（Application）

对每个争点写完整三段论：

```text
大前提：第 X 条规定……（构成要件：A、B、C）
小前提：本案中，A 有【证据】；B 有【证据】；C 有【证据】。
涵摄：本案事实该当 A、B、C。
结论：因此，……
```

- 概念容易混淆时，先写一句“二者区别在于……”，再选边。
- 因果/条件关系：写清“必要条件/充分条件”“多因一果/不作为义务”。
- 数值：公式、代入、中间结果、单位四行写全；用脚本复算。

## 5. 反方与例外（Counter / Exception）

| 反方/例外 | 依据 | 是否成立 | 对结论的影响 |
|---|---|---|---|
| 反方论证 1 |  |  |  |
| 例外/但书 1 |  |  |  |
| 过失相抵/免责 |  |  |  |

- 至少一个反方 + 一个例外；如果确实没有，写“经检索未见……”，不要省略。
- 例外成立时，明确它削弱的是责任成立还是责任范围。

## 6. 结论（Conclusion）

```text
结论：……
限定：以……为前提；若……则……。
射程：仅回答……，不处理……。
```

- 结论不得超出请求/题目/事实；超出部分标“不处理”或“另案解决”。
- 量罚/责任分配要写比例与理由，不写“酌情”了事。

## 7. 提交前一致性自检

- [ ] 争点句与结论一一对应，没有多答或漏答
- [ ] 每条规范都核验过时效与版本
- [ ] 每个要件都有事实与证据，缺口已标“待证”
- [ ] 没有互斥结论并存（有效/无效、有罪/无罪、成立/不成立）
- [ ] 数值用脚本复算，结论与示例一致
- [ ] 例外/但书、举证责任、结论射程都写了
- [ ] 跑 `python scripts/logic_linter.py <文件>`，critical/major 清零后再提交

## 8. 与自动体检的关系

| 阶段 | 工具 | 作用 |
|---|---|---|
| 生成前 | 本脚手架 | 把结构外化，减少缺环/先行/遗漏 |
| 生成后 | `logic_linter.py` | 8 项确定性筛查，定位断点 |
| 法条 | `statute_verifier.py` | 时效/版本人工核验并留痕 |
| 复核 | `templates/logic_review_template.md` | 矩阵热力图 + issue + 修复顺序 |

> 脚手架和体检都不能替代教师/律师判断；它们的作用是让“逻辑断点”可见、可定位、可复测。
