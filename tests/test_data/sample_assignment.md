# 法学案例分析作业

## 案件名称：张某与李某相邻关系纠纷案

### 一、案件事实

张某与李某系邻居关系。2025年3月，李某在自家门口通道处堆放建筑石子，堆高近2米。张某多次通过微信要求李某移除石子堆，李某以"正在施工、过几天就搬"为由拖延。

2025年5月某日暴雨后，石子堆部分塌落。次日清晨，张某出门上班时踩到散落的石子滑倒，致右腿骨折，花医疗费3.2万元，误工45天。张某遂起诉李某要求赔偿全部损失。

### 二、法律分析

本案的核心问题在于李某的行为是否构成侵权，以及张某能否获得全额赔偿。

根据《中华人民共和国民法典》第一千一百六十五条的规定，行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。本案中，李某在公共通道堆放石子，未尽到合理的安全保障义务，存在明显过错。其堆放行为与张某的损害之间存在因果关系，因此李某应当承担侵权责任。

根据《民法典》第一千一百七十三条的规定，被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。本案中，张某作为成年人，在暴雨后出门应当预见到地面可能存在碎石，行走时应当保持谨慎。张某未尽到必要的注意义务，对损害的发生也有一定过错。

综合来看，李某应承担主要责任（约70%-80%），张某应承担次要责任（约20%-30%）。

### 三、结论

李某的行为构成侵权，应当赔偿张某的医疗费、误工费等损失。但由于张某自身也有一定过错，李某的赔偿责任可以相应减轻。张某应获得约70%-80%的赔偿，即约2.24万-2.56万元的医疗费，加上相应的误工费。
