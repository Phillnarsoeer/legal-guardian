## 二、测试环境

```bash
cd LegalGuardian_v4.2.0
python --version        # 需 >=3.9；本机 3.12.10 ✓
python tests/run_smoke.py               # 全量 44 项（含全量校准，约 1-2 分钟）
python tests/run_smoke.py --quick       # 跳过 2 项慢检（42 PASS + 2 SKIP）
```

## 三、自动化运行器

- 状态位：`PASS` 符合预期 / `FAIL` 意外失败（影响退出码）/ `KNOWN` 已记录缺陷 / `SKIP` 被 --quick 跳过
- 退出码：0 = 无意外失败。CI 门禁：`python tests/run_smoke.py && echo "SKILL OK"`
- 报告：控制台表格 + `tests/smoke_report.md`

**剩余 5 项召回盲区（基准设计限制，非代码缺陷）**：BM-T2-002（F7/F11：题干无计算信号与混淆词对）、
BM-T6-002（F16：题干无偏题信号）、BM-T7-002（F2/F15：题干含"构成要件"指令词、单一罪名非降维场景）、
BM-T3-002（F14：题干非作答文本，无判断词）、BM-T8-002（F17/F18：题干不足 100 字且无事实标注）。
以上均以**题干而非完整作答**作为输入所致；检测器对完整作答的召回以 REG-001~010 回归集为准（100%）。
